# Документація кваліфікаційного проєкту

**Тема:** Проєктування та розробка масштабованої системи безпечного обміну повідомленнями з наскрізним шифруванням на основі ротації сесійних ключів та протоколу Double Ratchet

**Спеціальність:** F2 «Інженерія програмного забезпечення»

**Виконавець:** Залога Нікіта Іванович

**Науковий керівник:** Газдюк Катерина Петрівна

Документація ведеться за методологією Docs-as-Code: текст пояснювальної записки зберігається в Git поруч із вихідним кодом (`/src`) і проходить той самий цикл змін через гілки та Pull Request.
