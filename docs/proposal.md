# Thesis Proposal

## 1. Попередня робоча назва проєкту
* **Українською мовою:** Проєктування та розробка масштабованої системи безпечного обміну повідомленнями з наскрізним шифруванням на основі ротації сесійних ключів та протоколу Double Ratchet
* **English:** Design and Implementation of a Scalable End-to-End Encrypted Messaging System Based on Epoch Key Rotation and Double Ratchet Protocol

---

## 2. Актуальність та проблематика
Сучасні комунікаційні платформи піддаються постійним векторам атак типу Man-in-the-Middle (MITM), витокам даних на рівні сховищ сервера та компрометації довготривалих криптографічних ключів. Більшість стандартних корпоративних систем покладаються на шифрування каналу передачі даних (TLS/HTTPS), що залишає текстовий та файловий вміст вразливим для аналізу на стороні централізованого бекенду або скомпрометованої інфраструктури провайдера.

Інженерна складність полягає у забезпеченні властивостей Forward Secrecy (прямої таємності) та Post-Compromise Security (безпеки після компрометації) у багатокористувацьких чатах та каналах без надмірного зростання обчислювальної складності. Необхідно синхронізувати криптографічні стани та епохи ключів (Sender Key Chains) між множиною гетерогенних клієнтських сесій через асинхронний ненадійний транспорт за умов роботи клієнтів в офлайн-режимі, гарантуючи нульове знання (Zero-Knowledge) серверної частини про вміст конвертів.

---

## 3. Сформована ідея продукту
Розробка клієнт-серверної криптографічно захищеної платформи реального часу (**Zero-Knowledge End-to-End Encrypted Messaging Platform**).

Архітектура рішення базується на суворому розмежуванні доменів відповідальності:
* **Клієнтський рівень:** Повна ізоляція генерації, деривації та локального персистентного збереження криптографічних матеріалів; безпосереднє виконання алгоритмів шифрування та верифікації цілісності на кінцевих пристроях користувача.
* **Серверний рівень:** Абстрактний роутер зашифрованих конвертів, координатор черг асинхронної доставки для тимчасово відключених пристроїв, сервіс керування епохами сесійних ключів та сховище публічних криптографічних сертифікатів без доступу до приватних ключів і відкритого вмісту повідомлень.

---

## 4. Детальний опис функціоналу (Core Features)

1. **End-to-End Encryption Engine**  
   Генерація та збереження криптографічних ідентифікаторів, реалізація клієнтського ratchet-механізму для парних чатів та управління розподілом симетричних ключів відправника.

2. **Key Epochs & Rotation Management**  
   Автоматизоване відкликання та регенерація ключів шифрування каналів і групових чатів при зміні складу учасників або досягненні лімітів повідомлень за часом / кількістю, що захищає від витоку історії.

3. **Duplex WebSocket Messaging Engine**  
   Сервіс маршрутизації зашифрованих пакетів даних та статусів присутності користувачів через збережені WebSocket-з’єднання з гарантією дедуплікації повідомлень та збереження порядку доставки.

4. **Background Task Pipeline**  
   Асинхронний менеджмент інвалідації сесійних токенів, очищення застарілих ключів та агрегація аудиту безпеки через брокер черг повідомлень.

5. **Захищене об’єктне сховище вкладень**  
   Завантаження та роздача мультимедійних файлів, де клієнт локально шифрує блоб симетричним ключем, передає шифротекст в об’єктне сховище та передає ключ дешифрування виключно всередині E2EE-конверта.

6. **Криптографічна верифікація автентичності**  
   Генерація та взаємна візуальна / цифрова верифікація відкритих ключів між співрозмовниками для повного запобігання підміні публічних ключів на рівні директорії серверів (MITM-захист).

## 5. Попередній інструментарій та технологічний стек

### Мови програмування
* **Python**
* **TypeScript**

### Архітектурні патерни та концепції
* **Domain-Driven Design (DDD)** з ізоляцією доменів `crypto`, `chats`, `messages`, `users`, `files`
* **Signal Protocol Primitives** (Double Ratchet Algorithm, Extended Triple Diffie-Hellman / Sender Key Distribution Protocol)
* **Zero-Knowledge Architecture** (сервер оперує виключно шифрованим текстом, епохами та метаданими)
* **Event-Driven Communication** (WebSocket, черги фонових задач)

### Фреймворки та бібліотеки
* **Backend:** FastAPI (асинхронний стек REST API та WebSocket), SQLAlchemy Core/ORM (мапінг реляційних моделей), Alembic (керування міграціями структури БД), Celery (розподілена черга фонових завдань), PyCryptodome / Cryptography (серверна криптографічна валідація)
* **Frontend:** Angular (модульна SPA-архітектура на базі Signals та RxJS), Web Crypto API (алгоритми ECDH, AES-GCM, HKDF, SHA-256)

### Бази даних та сховища
* **PostgreSQL:** реляційна персистентність користувачів, пристроїв, епох ключів та метаданих чатів
* **MongoDB:** документоорієнтоване сховище зашифрованих конвертів повідомлень та асоційованих метаданих
* **Redis:** in-memory брокер сесій, швидке кешування станів онлайн та брокер задач Celery
* **MinIO:** S3-сумісне сховище для зашифрованих бінарних вкладень

### DevOps, DevSecOps та інженерні інструменти
* **Docker & Docker Compose:** мультиконтейнерна оркестрація для середовищ розробки та тестування
* **Pytest & Jasmine/Karma:** модульне тестування бізнес-логіки та наскрізні тести інтероперабельності криптографічних примітивів між Python та TypeScript
* **Nginx:** Reverse Proxy, термінація TLS, маршрутизація WebSocket-трафіку та статики
* **Git:** версіонування, дотримання угод Conventional Commits, Docs-as-Code
